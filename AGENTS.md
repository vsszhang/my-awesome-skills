# Repository Instructions

- Keep each skill under `skills/<skill-name>/`.
- Every skill must contain `SKILL.md` with valid `name` and `description` frontmatter.
- Keep commit messages concise and in English.
- Use `feat:` for features, `fix:` for bug fixes, and `refactor:` for refactors.
- Commit by functional module; do not combine unrelated skill changes.
- Run `python3 scripts/validate-skills.py` before committing.
